社团管理系统 · 前端方案

三个设计方向，选一个继续做深

三个方向功能完全相同，差别在语气、密度与形制。每个方向都已做出登录页、概览、成员管理三个界面， 带真实动效与可交互的筛选、加载、空状态，可以直接点开操作。

A · 静默墨蓝

浅色

常规管理控制台。侧栏导航、面板加表格，语气克制，一眼能看懂。

强调色
钴蓝 #3553c6
密度
中高，适合成天泡在后台的人
形制
容器 10px，无胶囊
动效
克制，只在首次进入时播一次

适合：评委偏好稳妥专业、你想少踩坑。这是三者里最不容易出错的方向。

打开完整原型 直接看成员管理

B · 石墨终端

深色

技术社团自己的管理台。等宽数字、细线分隔、密度最高，气质接近开发工具。

强调色
祖母绿 #2fa37a
密度
最高，一屏看最多信息
形制
容器 6px，直角感更强
动效
最明显，含随滚动绘制的趋势线

适合：想靠观感抓人。深色界面在答辩投屏时最抓眼，但需要你对深色配色的细节有耐心。

打开完整原型 直接看成员管理

C · 留白方格

浅色

给不常来后台的普通成员用。顶部导航取代侧栏，卡片网格取代密集表格，留白最大。

强调色
赭红 #b34a26
密度
最低，一屏只讲一件事
形制
容器 16px，按钮标签全胶囊
动效
适中，格子随滚动依次浮现

适合：想让系统看起来不像后台。移动端体验最好，但一屏能承载的模块数最少。

三个方向都实现了这些

不是静态贴图。下面的状态在每个方向里都能真实触发，建议点一遍再决定。

登录校验

留空提交会显示行内错误，填上任意内容即可进入后台。

加载骨架屏

进入成员管理时会先出现与最终表格同形的占位块，不会发生布局跳动。

搜索与筛选

按姓名、学号、手机号搜索，叠加部门与状态筛选，结果条数实时更新。

空状态

筛不出结果时会出现空状态面板，并给一个清空条件按钮。

未完成模块占位

点侧栏里其他模块会看到明确的"尚未绘制"占位，不会假装有内容。

降低动态偏好

系统开启"减少动态效果"后，所有动画折叠为静态，页面照常可用。

需要你知道的三件事

照片是占位图，必须替换

登录页的照片来自公共图库，只用来验证版面。请换成社团自己的活动照或校园照， 替换 img/panel-calm.jpg、img/panel-graphite.jpg、 img/panel-quiet.jpg 即可，尺寸保持竖向比例效果最好。 另外活动列表目前刻意没有放封面图，因为图库里的照片题材对不上，接入真实照片后再补。

所有数据都是假的

成员姓名、学号、手机号、金额全部是构造的演示数据。其中 82 名成员、3 场活动、 ¥1,260 余额来自你给的示例，其余数字按内部逻辑配平，例如余额等于期初结余加收入减支出。

这是设计原型，不是最终代码

原型用纯 HTML 与 CSS 手写，没有引入 Vue 或 Element Plus，目的是把视觉语言先定下来。 选定方向后，界面会用 Vue 3 加 Element Plus 重写，把这里的颜色、圆角、间距、 字号固化成一套主题变量，业务代码不碰这些值。
